অ্যাডমিন প্যানেল + ইউজার লগইন সেটআপ (একবারই করতে হবে, বিনামূল্যে)

১) console.firebase.google.com -> Add project (নাম যেকোনো)।
২) Build > Authentication > Get started > Sign-in method > "Email/Password" চালু করুন (Enable)।
৩) Build > Firestore Database > Create database (Production mode)।
৪) Firestore > Rules ট্যাবে firestore.rules ফাইলের লেখা পুরোটা বসিয়ে Publish করুন (অ্যাডমিন নাম্বার 01989923281 আগে থেকেই বসানো আছে)।
৫) Project settings (⚙️) > Your apps > Web (</>) অ্যাপ যোগ করুন; যে firebaseConfig দেখাবে তার apiKey, authDomain, projectId, appId কপি করে config.js-এ বসান। config.js-এ adminId-ও একই নাম্বার দিন।
৬) GitHub-এ index.html, config.js, sw.js ... সব আপলোড করুন।
৭) অ্যাপ খুলে "রেজিস্ট্রেশন"-এ আপনার অ্যাডমিন নাম্বার দিয়ে আইডি খুলুন — আপনি সরাসরি অ্যাডমিন হবেন, হোমের ওপরে 🛡️ বাটন আসবে।

ব্যবহারকারী: রেজিস্ট্রেশনে নাম, আইডি নাম্বার (মোবাইল), পাসওয়ার্ড দিলে আপনার প্যানেলে রিকোয়েস্ট আসবে। অনুমোদন করলে তবেই অ্যাপ খুলবে।
অ্যাডমিন প্যানেলে: অনুমোদন, ব্লক/আনব্লক, ডিলিট। ব্লক বা ডিলিট করলে ব্যবহারকারীর অ্যাপ সঙ্গে সঙ্গে লক হয়ে যায়।
ভবিষ্যতে সব ম্যানেজ করা যাবে অ্যাপের অ্যাডমিন প্যানেল থেকে; কোড বদলাতে হলে শুধু GitHub-এ ফাইল আপলোড করুন।

সীমাবদ্ধতা: এটি স্ট্যাটিক (GitHub Pages) অ্যাপ, তাই লক শুধু অ্যাপের ভেতরে কাজ করে। কেউ কোড কপি করে নিজের কাছে চালালে তা আটকানো যায় না; আর ডিলিট করলে Firebase-এ ঐ নাম্বারের লগইন অ্যাকাউন্টটা থেকে যায় (অ্যাপে ঢুকতে পারে না), পুরোটা মুছতে চাইলে Firebase Console > Authentication > Users থেকে মুছুন। ইন্টারনেট ছাড়া অনুমোদিত ইউজার সর্বোচ্চ ৩০ দিন অ্যাপ চালাতে পারবে।
